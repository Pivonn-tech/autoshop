## 🔄 User Flow

```
Visit Marketplace
       ↓
Select Filters (Optional)
       ↓
View Filtered Results
       ↓
Browse Product Cards
       ├→ Click Contact Seller
       ├→ Click View Details
       ├→ Apply for Financing
       ├→ Request Inspection
       ├→ Verify Mileage
       └→ Get Insurance
       ↓
Add to Cart (if applicable)
       ↓
Proceed to Checkout
       ↓
Complete Purchase
```

## 📊 Filter Flow

```
START
  ↓
Make: Select (or leave as "Any")
  ↓
Year: Select Range (or leave as "Any Year")
  ↓
Price: Enter Min/Max (or leave blank)
  ↓
Transmission: Select (or leave as "Any")
  ↓
Color: Select (or leave as "Any")
  ↓
[Clear Filters Button Available]
  ↓
Results Update in Real-Time
```
